오류를 알리는 방법

문의 페이지의 이메일, 전화, 카카오톡 오픈채팅으로 알려주세요. 페이지 주소, 틀린 항목, 바르다고 보는 내용과 근거 자료 주소를 함께 보내 주시면 빨리 확인할 수 있습니다.

정정은 이렇게 처리합니다

  1. 보내 주신 근거와 페이지에 적힌 출처 원문을 함께 다시 엽니다.
  2. 원문으로 확인되면 값을 고치고, 같은 자료를 쓰는 비교 도구·비교표·가이드를 함께 고칩니다.
  3. 자료끼리 값이 다르면 한쪽을 고르지 않고 둘 다 적습니다. 공식 자료로 확인되지 않으면 해당 칸을 비웁니다.
  4. 법령·제도 안내나 안전에 관한 오류는 다른 수정보다 먼저 처리합니다.
  5. 고친 날짜와 내용을 아래 기록에 남기고, 해당 페이지의 최종 확인일을 바꿉니다. 오타·줄바꿈 같은 사소한 수정은 기록에서 뺄 수 있습니다.

수정 기록

아래 기록은 사이트 저장소의 실제 변경 기록을 바탕으로 적었습니다(최신순).

  1. 2026-10-26 포장 단위 가이드·사과·자두 가이드·목록 페이지

    포장 단위 가이드 3개(김장 채소, 과일 상자, 통·개로 파는 과채)를 다시 썼습니다. 페이지에 없는 도매 가격표의 ‘행’을 가리키던 문장과 품목 이름을 늘어놓은 제목을 고치고, kg당·개당 계산 순서와 가상 계산 예시, 농촌진흥청 자료의 품종별 과실 무게로 상자 개수를 어림하는 표를 더했습니다. 사과·자두 가이드에 농사로 자료의 자두 품종별 수확기·과실 무게·당도를 더했습니다. 비교표·가이드 목록 페이지에서 광고 코드를 뺐고, 개인정보처리방침에 Google 외 광고 업체의 쿠키와 해제 방법을 덧붙였습니다. 소개의 주소 내력을 저장소 기록으로 확인되는 내용에 맞게 고쳤습니다.

  2. 2026-10-26 사이트 전체

    편집 원칙과 정정·수정 기록 페이지를 새로 만들었습니다. 모든 비교표·선택 가이드·도구에 작성·관리 정보, 게시일과 최종 확인일, 기관·확인일이 붙은 출처 목록, ‘범위와 한계’를 붙였습니다. 운영자 정보(대표, 사업자등록번호, 주소, 고객센터, 카카오톡 문의)를 소개·문의 페이지와 바닥글에 실었고, 개인정보처리방침에 광고 쿠키와 방문 통계(Cloudflare Web Analytics) 내용을 보강했습니다. 사이트 안내 페이지에서 광고 코드를 뺐습니다.

  3. 2026-10-26 트랙터 탁송 견적 비교법

    게시일 표기를 저장소 기록에 맞춰 2026-09-20에서 2026-09-16으로 고쳤습니다. 더 이상 열리지 않는 농촌진흥청 영상 링크를 빼고 농사로 ‘기종별 안전수칙’ 자료로 바꿨습니다.

  4. 2026-10-26 출처가 없던 가이드 3개

    근처 농산물 글 고르기, 만나서 받기·택배 고르기, 쇼핑몰·직거래 고르기 가이드에 사기가 의심될 때 문의할 공식 창구(경찰청 사이버범죄 신고시스템)를 출처로 붙였습니다.

  5. 2026-10-26 몽골어 페이지(/mn/)

    몽골어가 Google AdSense 지원 언어가 아니어서 검색 색인 제외(noindex)로 바꾸고 광고 코드와 사이트맵 항목을 뺐습니다. 보리장터 몽골어 이용자를 위해 페이지는 그대로 둡니다.

  6. 2026-10-26 고구마·감자·사과 비교표, 밭 작업 장비 비교

    원문을 다시 대조해 고구마 호감미·풍원미의 병해충 저항성(근거 없는 더뎅이병 표기 삭제, 뿌리혹선충 반영), 감자 새봉의 역병 저항성, 추백의 모양, 은선의 휴면기간 표기를 고쳤습니다. 농기계 내용연수가 국가·지자체의 중고 농기계 구매·임대 기준이라는 점, 트랙터 중고거래 신고를 누가 하는지, 면세유 감면 기한(2026-12-31)과 정부 연장안을 덧붙였습니다. 첫 질문에 맞는 후보가 대결에서 밀리지 않도록 후보 선정 방식을 바꿨습니다.

  7. 2026-10-26 판매글 작성 가이드 8개

    품종명·실중량·수확일, 명판 형식명·시간계·작업기, 날짜 구분을 중심으로 다시 쓰고 법령 근거(양곡 표시사항, 형식표지판, 차대 제조번호, 검정 미필 판매 금지, 면세유 서류)를 붙였습니다. 쌀 가이드에 양곡 표시 항목을 더하고 트랙터 가이드의 중고거래 신고 문장을 고쳤습니다. 휴대폰에서 표가 화면 밖으로 넘치던 문제를 고쳤습니다.

  8. 2026-10-26 비교 월드컵·비교표

    질문에 답해도 결과에 반영되지 않던 문제를 고치고, 감자·고구마·사과·배·밭 작업 장비 5개 주제와 공식 출처가 붙은 후보 55개로 비교 도구를 다시 만들었습니다. 같은 자료로 품종·장비 비교표 5개를 새로 만들었습니다.

  9. 2026-10-26 이름·아이콘·문의처

    사이트 이름을 농사월드컵에서 농사 비교 월드컵으로 바꿨습니다. 예전 오컬트 사이트 시절의 아이콘과 앱 이름을 바꾸고 404 안내 페이지를 추가했습니다. 메일 수신이 되지 않던 문의 주소를 운영자 메일로 바꿨습니다.

  10. 2026-10-26 가락시장 시세 관련 가이드

    보리장터의 품목별 가락 시세 페이지가 없어져, 링크를 공식 가격 조회 안내로 바꾸고 없어진 표를 가리키던 문장을 고쳤습니다.

  11. 2026-10-15 중고 트랙터 두 후보 확인표

    비교 기준일·자료 메모 칸과, 확인하지 못한 항목이 그대로 남는 복사·인쇄 기능을 추가했습니다.

    중고 트랙터 두 후보 확인표와 몽골어 농기계 비교 페이지 2개를 추가했습니다.
